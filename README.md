# ¡En el aire!

Concurso de preguntas de la asignatura **Animación y Nuevas Tecnologías en Publicidad**.

Al final de cada sesión, el alumnado responde un cuestionario con formato de concurso de televisión: cada acierto vale entre 1000 y 500 puntos según la rapidez de la respuesta, y al terminar se genera un resguardo con un código de verificación.

Los cuestionarios están cifrados: solo se pueden abrir con la contraseña que la profesora facilita en clase.
